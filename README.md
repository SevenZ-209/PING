
# PING

**Less planning. More hanging out.**

PING is a mobile social application that helps friends organize spontaneous activities without lengthy group conversations.

## The Problem

Making plans with friends often requires messaging multiple people, checking availability, and coordinating details.

## The Solution

PING lets users create an invitation (a "Ping") and invite friends to join activities such as coffee, studying, dining, or watching movies.

## MVP Features

- Authentication and user profiles
- Friend requests and friendships
- Private groups and group invitations
- Group and direct Pings
- Join, leave, and participation approval
- Ping deadlines and automatic expiration
- Push notifications

## Tech Stack

**Mobile:** React Native, Expo, TypeScript

**Backend:** Java, Spring Boot, Spring Security

**Database:** PostgreSQL

**Infrastructure:** Docker, GitHub Actions

**Testing:** JUnit, Mockito, Testcontainers

## Architecture

The backend follows a Modular Monolith architecture with six logical modules:

- Identity
- Social
- Groups
- Pings
- Notifications
- Lifecycle
